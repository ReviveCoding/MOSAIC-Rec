The mapped array SHA-256 is `bb114e3d89e3983aa3798f72e0d3756f535c881366a8bacb65e44f70a9c301ae`. It is eligible for **local publisher-feature research only**; no redistribution. The encoder and historical effective time are not established by the link alone, so no local image-extraction or temporal content-validity claim follows from using it.

A subsequent local alignment audit matched the publisher image index to the separately extracted MiniLM text index byte for byte across all 82,865 items, checked every vector for finiteness, and mapped 109 metadata tag categories plus title presence. Only item-local `tag` and `title` fields entered these derived arrays; the seven engagement aggregates remain excluded. The exact input and derived hashes are in `evidence/pixelrec_content_alignment_p1.json`. These vectors and arrays remain in WSL scratch and cannot be redistributed from this repository.
